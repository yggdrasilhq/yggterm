# Portable steering seeds

These generic seeds belong to the Ygg operating layer. Onboarding places a
versioned seed and private local policy beneath the selected Ygg root's
`steer/` organization. The public seed contains no deployment identity,
model-account binding, private campaign or fleet topology.

The root instruction is a progressive pointer. Component detail belongs to
the yggterm skill and registered skills. Native memory-managed blocks and
other writers' instructions remain owned by those writers. Seed upgrades
are reviewed proposals; they never overwrite local policy silently.

See [the steering contract](../docs/spec-ygg-steer.md) and
[the fleet information contract](../docs/spec-ygg-sync.md). The legacy
private repository has a separately qualified retirement transaction;
adding these files does not delete it or reproduce its private content.

Canonical machine seed: [ygg-steer-seed.json](../.agents/skills/yggterm-agent-fleet/ygg-steer-seed.json). It is shipped adjacent to the portable generator; this directory is the documentation door.
